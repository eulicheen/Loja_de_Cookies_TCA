# 🔪 Ficha Brutal RPG

Site com sistema de login para mestre e player poderem editar suas fichas e campanhas.

## Sobre o projeto

A **Ficha Brutal RPG** é um projeto feito para praticar banco de dados. 
O site atualmente exibe apenas uma tela de login.
